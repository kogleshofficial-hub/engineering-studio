# ENGINEERING STUDIO

Industrial hardware × AI × full-stack software engineering interface.

Built by Koglesh R. Murugan and Yennamutan Muthukumaran.

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS v4
- React Server Components by default
- Vercel-ready architecture

## Engineering principles

- Evidence over claims
- Measurable performance over vanity metrics
- Hardware and software designed as one system
- Small, reviewable changes
- No direct pushes to `main`

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
